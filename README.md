Traffic Violations & Compliance Dashboard 🚦

## 🔍 Project Overview
Analyzed traffic violation trends and compliance types to identify improvement areas and monitor city-wise performance using Power BI.

## 📊 Features
- KPI cards for Total Violations, Active %, Ignored %, Resolution %
- Charts by violation type, city, and compliance category
- Environment monitoring (Managed vs Disabled)
- Violation Turnaround Time (TAT) Analysis
- Filter visuals by Violation Type or Year

## 🧠 Key Insights
- Most violations were due to Red Light and Helmet issues.
- Tokyo and New York had the lowest number of active violations.
- 50% of violations were Severe – need policy action.
- Environments were mostly Managed (85%) showing high device coverage.
- High number of violations resolved within a week.
